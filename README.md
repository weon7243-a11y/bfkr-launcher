# BubbleFighter KR Launcher

BubbleFighter KR 접속기 배포 및 자동업데이트 저장소입니다.

## 다운로드

운영용 접속기는 [v1.0.7 운영 릴리스](https://github.com/weon7243-a11y/bfkr-launcher/releases/tag/v1.0.7)의 **BFKR-Production-Launcher.zip**을 받습니다. 압축을 풀어 **BF접속기.exe**와 **server.dat**를 게임 폴더에 넣으세요. 운영 VPN 주소는 26.43.139.87, 인증 포트는 17120입니다. 같은 Radmin VPN에 참가해야 합니다.

개발자 테스트용 접속기는 [테스트 최신 릴리스](https://github.com/weon7243-a11y/bfkr-launcher/releases/latest)의 **BFKR-Launcher.zip**을 받습니다. 로컬 테스트 인증 포트는 18120입니다. 테스트용 접속기를 일반 플레이어에게 배포하지 마세요.

게임 파일은 별도로 준비해야 합니다. 접속기 실행 파일 이름 **BF접속기.exe**는 유지하세요.

## 가입과 로그인

- 처음 가입할 때는 운영자가 발급한 초대코드, 닉네임, 숫자 접속번호를 입력합니다.
- 기존 계정은 닉네임과 접속번호로 로그인합니다. 가입 후 초대코드를 다시 입력할 필요는 없습니다.
- 초대코드는 유효기간과 가입 가능 인원 제한이 있습니다.

## 자동업데이트

운영 접속기는 `BFKR-Production-Launcher.zip`이 포함된 새 운영 프리릴리스를, 테스트 접속기는 별도의 테스트 릴리스를 확인합니다.
새 버전이 있으면 GitHub가 제공한 SHA-256 및 파일 크기로 다운로드를 검증하고 접속기를 교체합니다.
게임이 실행 중이면 게임 종료 후 다음 접속기 실행 때 업데이트합니다.
새 접속기가 정상 실행되지 않으면 이전 실행 파일로 복구합니다.
게임 데이터와 접속 설정은 접속기 교체 대상에 포함하지 않습니다. 커스텀 맵 데이터는 게임 서버의 별도 검증된 맵 패치 채널로 내려받습니다.

이 저장소에는 접속기 배포 파일과 안내만 게시합니다. 서버 소스, 계정 데이터, 접속번호,
초대코드, 관리 인증정보는 올리지 않습니다.
